# Fieldra Desktop downloads

Direct downloads of [Fieldra Desktop](https://fieldra.luminex-technology.com/desktop) for macOS and Windows.
The source code lives in a private repository; this repository only holds the release files, published
automatically by its release workflow.

**We recommend the Mac App Store or the Microsoft Store**: they install the right version, keep it up to
date, and show no security prompts. Use these downloads on computers without store access.

| Computer | Download (always the latest version) |
| --- | --- |
| Any Mac | [Fieldra-macOS-Universal.dmg](https://github.com/luminex-ltd/fieldra-desktop-releases/releases/latest/download/Fieldra-macOS-Universal.dmg) |
| Mac with Apple silicon | [Fieldra-macOS-AppleSilicon.dmg](https://github.com/luminex-ltd/fieldra-desktop-releases/releases/latest/download/Fieldra-macOS-AppleSilicon.dmg) |
| Intel Mac | [Fieldra-macOS-Intel.dmg](https://github.com/luminex-ltd/fieldra-desktop-releases/releases/latest/download/Fieldra-macOS-Intel.dmg) |
| Any Windows PC | [Fieldra-Windows-Setup.exe](https://github.com/luminex-ltd/fieldra-desktop-releases/releases/latest/download/Fieldra-Windows-Setup.exe) |
| Windows x64 | [Fieldra-Windows-x64-Setup.exe](https://github.com/luminex-ltd/fieldra-desktop-releases/releases/latest/download/Fieldra-Windows-x64-Setup.exe) |
| Windows on ARM | [Fieldra-Windows-arm64-Setup.exe](https://github.com/luminex-ltd/fieldra-desktop-releases/releases/latest/download/Fieldra-Windows-arm64-Setup.exe) |
| Windows, no installer | [x64](https://github.com/luminex-ltd/fieldra-desktop-releases/releases/latest/download/Fieldra-Windows-x64.zip) · [ARM64](https://github.com/luminex-ltd/fieldra-desktop-releases/releases/latest/download/Fieldra-Windows-arm64.zip) · [32-bit](https://github.com/luminex-ltd/fieldra-desktop-releases/releases/latest/download/Fieldra-Windows-x86.zip) |

Checksums for every file are in `SHA256SUMS.txt` on each release.

On Windows, a direct download may show "Windows protected your PC": choose **More info › Run anyway**.
